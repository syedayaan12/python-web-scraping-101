# Python Web Scraping & Data Extraction 🕷️

A collection of Python scripts designed to extract structured B2B data, book catalogs, and product listings using `requests`, `BeautifulSoup`, and `pandas`.

## 📌 Features
- **HTTP Parsing:** Fetching HTML DOM elements using custom headers.
- **Data Export:** Parsing raw elements into structured `pandas` DataFrames and exporting directly to `.csv`.
- **Pagination Handling:** Iterating across multi-page web directory listings efficiently.

## 🛠️ Stack & Tools
- Python 3.x
- BeautifulSoup4
- Pandas
- Requests
